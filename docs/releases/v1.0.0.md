# HCS Discovery Studio v1.0.0 Stable

**Open science. Reproducible discovery. Made with ❤️ by hcsmedia.**

We are proud to announce the **v1.0.0 Stable Release** of **HCS Discovery Studio**, a local-first, open-source computational drug discovery and virtual screening workbench.

This stable release transitions the project from preview into a genuinely stable, mathematically rigorous, scientifically honest, and fully packaged platform for Windows and Linux.

---

## Highlights in v1.0.0

### 🔬 Real Scientific Engine Integrations
- **AutoDock Vina CPU Docking:** Integrated native CPU structure-based virtual screening (`dock.vina`). Features automated RDKit 3D conformer embedding, MMFF94 force field optimization, Gasteiger charges, AutoDock PDBQT atom typing, flexible torsion calculations, receptor bounding box checks, multi-pose extraction, and PDBQT-to-SDF conversion.
- **Learned Property Prediction:** Integrated Delaney (2004) ESOL aqueous solubility modeling with leverage-based uncertainty calibration and applicability domain detection (`predict.property`). Integrated Wager et al. (2010) CNS Multiparameter Optimization (CNS MPO) scoring for blood-brain barrier permeability profiling.
- **Scaffold Splitting:** Added Bemis-Murcko generic scaffold extraction and leakage-free dataset splitting for cheminformatics model benchmarking.
- **Public Data Connectors:** Added NCBI PubChem and EMBL-EBI ChEMBL connectors with rate limiting, exponential backoff, and strict local-first network policy isolation (`local` mode blocks remote egress by default).

### ⚙️ DAG Multi-Branch Workflows
- **DAG Branching & Joins:** Extended workflow engine from linear chains to full Directed Acyclic Graphs (DAGs) using Kahn's topological sort, fan-out execution, cycle detection, and compound-identity table joining (`table.join`).

### 🤖 Safe Local Research Assistant
- **Three Modes:**
  - `Ask`: Read-only queries over projects, datasets, compound metrics, and computational engine availability.
  - `Plan`: Formulates validated DAG workflows with schema verification, resource estimates, and scientific limitation disclosures without state mutations.
  - `Run`: Executes approved typed allowlisted tools with strict server-side validation and human approval gating.
- **Prompt-Injection Defense:** Untrusted data payloads from compound names, SDF/CSV files, or external databases are strictly isolated inside `<untrusted_data>` containers.

### 📊 Scientific Transparency & Reporting
- **Deb's Fast Non-dominated Sorting:** Replaced greedy sorting with Deb's algorithm, guaranteeing Pareto dominance invariance under row permutation.
- **Table Truncation Disclosures:** Markdown and HTML reports prominently disclose when tables are truncated for rendering performance (>200 and >500 rows), and provide complete un-truncated CSV, JSON, and SDF exports.
- **Cache & Deletion Lifecycle:** Bounded cache size and age with `hcs-discovery cache prune`, and ensured transactional cascade deletion of database entities and on-disk files.

### 🎨 Authentic Visual Identity & Branding
- Original vector icon mark (`hcs-discovery-mark.svg`), wordmark (`hcs-discovery-wordmark.svg`), and high-resolution 1280x640 OpenGraph social preview card.

## Scientific Caveat & Policy

> **Important Scientific Principle:** Computational docking scores, predicted physicochemical properties, and ranking indices are prioritisation signals for virtual screening, not experimental proof of biological binding, clinical safety, or therapeutic efficacy. All computational findings require wet-lab experimental validation.
