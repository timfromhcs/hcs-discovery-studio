## What this establishes

A repeated similarity search over an imported dataset no longer pays the
fingerprinting cost: the packed matrix is read back and its checksums verified in
about 2 % of the cold time on this host. The first search still pays the full cost
plus the store (724 ms vs 657 ms), which is the expected one-time overhead.

## What it does not establish

- The library is synthetic (10 base molecules cycled). Real ECFP fingerprints have
  a wider bit-density spread, which affects search time, not the caching overhead.
- One host, one SQLite file, one process. No claim about concurrent writers or a
  remote database.
- The 43× is the ratio of *re-fingerprinting* to *cache read*, not a claim about
  end-to-end search latency, which also includes the kernel and ranking.
